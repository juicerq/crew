# Keeping sources useful for the next session

Store trusted knowledge sources and places to gain practical experience in `RESOURCES.md`. Draw lesson claims from those sources rather than filling factual gaps with guesses.

Organize entries by their purpose:

```md
# Strength Training Resources

## Knowledge

- Book: The Science and Practice of Strength Training, by Zatsiorsky and Kraemer
  Use for programming, adaptation, and recovery; add the verified edition or source link when available.

## Wisdom (Communities)

- Local: Tuesday strength class at the learner's gym
  Use for real-time feedback on lifts when the class fits the learner's budget.
```

Prefer primary sources, recognized experts, peer-reviewed work, and strongly moderated communities. Exclude marketing presented as education. For each real entry, include a verified link when available and a sentence explaining its coverage and when to use it; a bare URL will not guide a later lesson.

A source may belong to only one group. If a needed area has no trustworthy source yet, name it under `## Gaps` so the next search has a target. Remove sources that prove wrong, shallow, or outside the mission instead of burying them under additions.

Record a preference against joining communities here. Future sessions can still answer practical questions without repeatedly proposing participation the user declined.
