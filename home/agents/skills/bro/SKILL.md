Rewrite your last message so the user can understand it on one reading. Use familiar words, connected sentences, and only the detail needed to keep its meaning.

Preserve conditions, negations, uncertainty, and the action requested. “The check passed, but delivery is still pending” must not become “It worked.” Explain an essential technical term briefly rather than deleting the distinction it carries. Return the simpler message directly.
